# Changelog

All notable changes are documented here. RhythmLint follows Semantic Versioning.

## [0.1.0] - 2026-08-08

### Added

- Local ICS audit with recurrence expansion, deduplication, and privacy-aware labels.
- Nine deterministic schedule-health rules for overlap, transition, meeting budgets,
  consecutive meetings, focus capacity, fragmentation, lunch, and outside-hours work.
- Console, JSON, Markdown, and self-contained HTML reports.
- Before/after calendar diffing with metric deltas and resolved/introduced findings.
- Deterministic focus/lunch repair overlay generation as an importable ICS file.
- Example calendars, bilingual documentation, CI, Pages demo, release packaging, and
  reproducible acceptance and repair commands.
