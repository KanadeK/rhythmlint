# Support

- Usage questions and reproducible bugs: GitHub Issues.
- Security or privacy vulnerabilities: private vulnerability reporting; see
  [SECURITY.md](SECURITY.md).
- Calendar-provider account or export problems: use that provider's support channel.

Please include the RhythmLint version, Node version, operating system, command, exit
code, and a synthetic or redacted ICS fixture. Never attach a private calendar export
to a public issue.
